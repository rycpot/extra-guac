dark mode

Dark mode for

The switch next to dark mode in the tools turns it on or off everywhere; the row below it excludes (in "all") or includes (in "sites") the site you're on. A site covers its subdomains.

Sites dark in "sites I pick" mode

Exclusions left as they are in "all sites" mode

Darken anyway pages that are dark on their own are normally left as they are; on these sites they're inverted too

How it works

The page is darkened from its very first paint (no white flash) by inverting it as a whole while keeping its colours' hues, so nothing can stay light — not even parts built from web components. Photos, videos, background pictures and video or map embeds are turned back to normal (slightly dimmed). Pages that are dark on their own are noticed and left as they are, page by page (the tools say "already dark").

      auto-refresh

      When a keyword is found

      Alert sound

      How it works

      Turn it on per tab in the popup: a fixed interval, or a random one between two values (seconds). Keywords (up to 20, any one counts) are matched against the page's visible text, ignoring case; they're only seen while the tab is in the foreground. The toolbar badge counts down on that tab.

      url shortener

      Keys are stored only in this browser. Links are counted per calendar month on this device; the free-plan limits shown are cutt.ly 30, TinyURL 30 and dub.co 25 links a month.

      How rules work

      docs.google.comdomain: that site and its subdomains. Empty = every site. A path (docs.google.com/spreadsheets) means "URL contains"; anything with \ ( * | is a regex.
      SY500 → SY1600find plain text: replaced as is (first match).
      /edit{line} → /copy{line} = rest of the URL, {word} = one path part, {number} = digits, {[a-z-]} = your own characters. Insert them in the target with {1}, {2}…

      auto ✓ / ✗Auto rules redirect as the page starts loading. The others run from the page's right-click menu, Redirect with rules, or go in the popup (for pages that have their own right-click menu).
      loopsA tab is never redirected again from a URL a rule just sent it to, and more than 4 redirects in 10 s pauses redirecting that tab for a minute.

      remove elements

      Sites click a name to turn it off or on · × deletes it · hover for its address · removals apply to the whole site and its subdomains

      How it works

      In the tools, page tab → remove elements → pick, then click everything you want gone (↑ selects the parent, Ctrl/⌘+Z puts the last one back, Esc or Enter when done). While picking, a panel in the corner lists what's removed on the site: point at an entry to see that element, the eye shows it again (or hides it again), × deletes it, and discard all puts back everything picked in that session without saving it. Removed elements stay hidden on every later visit — the page is held back until they're hidden, so they never flash, even on slow loads. Show removed on this site brings them back with a red dashed outline until you switch it off or restart Chrome.

      Site lists

      How it works

      Words and phrases are matched as whole words (or anywhere inside words, with partial matches on for that list), any case, and marked as pages load and change (infinite scroll, in-app navigation, live updates) without touching the page itself. A site's own list is drawn over the global one where both match. Limits: 1,000 global words, 300 per site, 200 sites, 100 characters each; at most 5,000 marks per page. CSV: one word or phrase per row (first column; a "word" header is fine). Import adds to the list and skips duplicates. In the tools: the main switch, exclude <site> from global, and <site> list to switch a site's list off without deleting it.

      clipboard history

      Keep

      and delete entries older than

      Pinned entries are kept for good and don't count towards the limit. Each entry holds up to 20,000 characters; longer copies are trimmed. Copying the same text again moves it to the top.

      Right-click menu

      Up to 20 pinned entries, offered only when you right-click somewhere you can type on a web page (a text box or an editable area). Choosing one types it in there. Chrome doesn't let extensions type into other extensions' windows or its own pages, so the menu isn't shown there.

      Never record on sites where copied text isn't saved, e.g. your bank or password manager

      History

      Saved: text you copy or cut on web pages with the keyboard, the right-click menu or a site's copy button. Not saved: copies in other apps or on Chrome's own pages, anything from password and one-time-code fields, and copies on the sites above. The history stays in this browser and is part of Drive backups and the settings file. Browse, search, pin and copy it from the tools.

      How it works

      Right-click any image → Upload image to … (with both hosts on, the item branches into the two). The link is copied, a notification confirms it, and it's listed in the popup's upload history.       backup

      Google Drive

      How to get a client ID (once, about 3 minutes)
      1. Open Google Cloud console and create a project (any name).
      2. Enable the Google Drive API for it.
      3. Google Auth Platform → Branding: set an app name and your email.
      4. Audience: choose External, then under Test users click + Add users and enter the exact Google account you'll connect with. Without this, Google stops the sign-in with “Access blocked: … has not completed the Google verification process” (403 access_denied). Changes can take a minute to apply.
      5. Clients → Create client: type Web application. Leave Authorized JavaScript origins empty (it only takes a bare domain and rejects this address with “Invalid Origin”). Under Authorized redirect URIs, click + Add URI and paste exactly, with the trailing /.
      6. Copy the client ID it shows into the box above and click connect.

      Tab Toolkit only asks for access to files it creates itself, and keeps snapshots in a folder named “Tab Toolkit backups”. The redirect URI depends on this copy of the extension: if you load it from another folder, it changes (add the new one to the same client). It has to be an OAuth client: an API key or a service account can't reach your own Drive.

      Auto-sync

      A snapshot is saved only when something changed: your bookmarks, and Tab Toolkit's settings and data (API keys included, blur rules, removed elements, histories). Older ones thin out like a time machine — the 3 latest, about 1 week, 2 weeks, 1 month, 2 months, 6 months and 1 year old, and the oldest one forever. Each browser's latest is always kept, and so is the copy taken before every restore or import (for 30 days).

      Snapshots

      Connect Google Drive to see your snapshots.

      restore settings replaces Tab Toolkit's settings and data with the snapshot's. restore bookmarks adds the snapshot's bookmarks in a new folder under Other bookmarks, next to the ones you have now. .html saves them as a bookmarks file any browser can import. Before every restore or import, the current settings are saved first — undo last restore below puts them back.

      Settings file

      Tab Toolkit's settings and data as a .json file, API keys and the Drive client ID included (not the Google sign-in) — keep it somewhere private. Import takes such a file or a Drive snapshot (.json.gz) and replaces the current settings and data.

How it works

Area: drag a box on the page, adjust it with the handles, then ✓ (or Enter) at its bottom-right. Tab: what's visible in the tab. Full: scrolls to the end of the page and stitches it together; very long pages are saved in numbered parts.

    Rule syntax
    John AppleseedPlain text: blurs that exact text (any case).
    Phone number: {number}Label stays visible, only the {…} part is blurred.
    {number}Digits with spaces and + ( ) - ., at least 4 digits. Stops at the first other character.
    {word}The next word.
    {line}Everything to the end of the line.
    {[\d()\- ]}Your own set of allowed characters.
    /regex/flagsJavaScript regex. Blurs the whole match, or only the (?<blur>…) group if present.

      How it works

      Turn it on per tab in the popup: a fixed interval, or a random one between two values (seconds). The keyword is matched against the page's visible text, ignoring case. The toolbar badge counts down on that tab.

      url shortener

      Keys are stored only in this browser. Links are counted per calendar month on this device; the free-plan limits shown are cutt.ly 30, TinyURL 30 and dub.co 25 links a month.

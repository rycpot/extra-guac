Theme

Open the tools in

The popup closes as soon as you click anywhere else, like a settings window or another tab. The side panel stays open beside the page and follows the tab you're on.

Tools layout

The popup's first three tabs. Drag a section to another tab, or up and down within one; the popup and side panel follow right away. Tab 3 shows up in the popup once it has something in it. The backup tab stays as it is.

About

Click the toolbar icon for the tools. ⏻ in the tools stops everything that is running: auto-refresh, keep awake, tab volume and blur.

dark mode

A site covers its subdomains. In the tools, the switch next to dark mode turns it on or off everywhere, and the row under it adds or removes the site you're on.

How it works

The page is darkened from its very first paint (no white flash) by inverting it as a whole while keeping its colors' hues, so nothing can stay light — not even parts built from web components. Photos, videos, background pictures and video or map embeds are turned back to normal (slightly dimmed). Pages that are dark on their own are noticed and left as they are, page by page (the tools say "already dark").

proxy

powered by

session switch

How it works

Keep several logins for the same site and switch between them in the session switch section of the popup (tab 3 unless you move it in general). Each profile is a saved login for one site: its cookies, its pages' localStorage and sessionStorage, and the app data some web apps keep in the page. The active profile is kept up to date while you use the site, so a login the site renews, or one you make again after being logged out, is saved as it changes. A profile can open its site through one of your Webshare proxies (the key goes in proxy): only that site goes through it, only while that profile is active, and if the proxy can't be used, the site doesn't open rather than open without it.

Cloud backup

When cloud backup (Google Drive or Dropbox, in backup) uploads a snapshot, every profile goes with it, so restoring that snapshot on another browser brings your profiles back too. They aren't encrypted: anyone who gets into your Drive or Dropbox could sign in as you on these sites. App data copies are left out, so it stays small: a few KB to a few hundred KB per profile, depending on how much the site keeps in its pages.

Profiles from the snapshot are added next to the ones here, inactive. Profiles already here, and every other setting, stay as they are.

Encrypted backup file

A backup holds every profile's saved logins, so anyone with the file and its passphrase can use those accounts. It is encrypted with the passphrase you choose here (PBKDF2 and AES-GCM), and the passphrase isn't stored anywhere. The Webshare key isn't included.

Restore

Profiles from the backup are added next to the ones here, inactive. Profiles already here are left as they are.

Sites

The sites you keep profiles for. Linked sites: some logins live on two domains, and then a switch has to swap both. For example, Jira and Confluence run on yourteam.atlassian.net but sign you in through atlassian.com, so link atlassian.com to atlassian.net; Stack Overflow's login also covers stackexchange.com. A linked site goes through the same profile, proxy included. Leave out Google and Microsoft sign-in domains: they tie logins to the device and break when swapped.

text from image

OCR.space key

Optional on the free plan: without a key of your own, Extra Guac's shared free keys are used. They're shared by everyone, so they can run out for the day or the month; then you're asked for your own. Free, no credit card: get a key with your email and paste it here. Your key is used instead of the shared ones and stored only in this browser.

Plan

Checking your key finds its plan and picks it here (PRO keys work only on the PRO servers, free keys only on the free one); you can still change it. Free: 25,000 images a month, 500 a day, up to 1 MB each. PRO plans use OCR.space's PRO servers (apipro1, and apipro2 if the first one doesn't answer; type another address only if the welcome email names one): 300,000 a month, no daily limit, up to 5 MB each. Selections are made smaller only when they're over the limit, so on PRO big areas stay sharper.

Engine

Engine 2 is fast and detects the language. Engine 3 is slower but better on handwriting, tables and 200+ languages; it has its own smaller quota (1,000 a month on the free plan). Whichever you start with, the card under the text switches to the other one and reads the same selection again.

How it works

text from image → area in the tools: drag a box over the text (resize or move it with the handles), then ✓ or Enter. Only that box is sent to OCR.space, and nothing else from the page. The text is copied and shown in a card at the bottom-right, where you can correct it and copy it again. The card stays until ✕ or Esc.

open other site urls in new tab

Sites links that leave these sites open in a new tab

Pick the websites where you want this. On those sites, a link that takes you to a different website opens in a new tab, so the page you were on stays open. Links that stay on the same website open normally.

To add a site, open the popup while you're on it and switch this on, or type its address below.

Ctrl/⌘ + click and middle-click keep working the way they always do.

Sometimes one website uses more than one address. For example, signing in on youtube.com sends you to google.com, so it opens in a new tab. To stop that, add google.com to the youtube.com row.

Quicker way: if a link opens in a new tab when it shouldn't, open the popup and click treat as same site.

Each subdomain is its own site

Sometimes one address is shared by many people. For example, alice.github.io and bob.github.io are two different people's pages, so a link from one to the other should open in a new tab. Common ones like github.io, vercel.app and blogspot.com already work this way.

If you find one that doesn't, add the shared part here. For example, add pages.acme.dev and then design.pages.acme.dev and sales.pages.acme.dev are treated as separate sites.

refresh on focus

Refreshes a tab when you come back to it (switching to its tab, or to its window from another window or app) if its address matches one of these. Switch it on for the page you're on with refresh on focus in the tools, or add one here. An address matches only exactly (github.com/notifications), unless it has a *, which stands for anything: github.com/*/pulls, or a whole site with *.google.com/*. The https://, a leading www., a #part and a trailing / don't count; a ?query does.

How it works

normal reloads the page; hard reloads it skipping the browser's cache. Expires after counts from when the entry was switched on (empty = never); an expired entry is switched off and stays here, and switching it on again starts its time over. If away at least refreshes only when you were away from the tab (on another tab, window or app) that long or longer, so going back and forth between tabs doesn't keep reloading it; 0 refreshes every time. A tab that's still loading isn't refreshed.

polish text

Groq key

Groq rewrites the text with an open AI model (Llama 3.3 70B, or the next one Groq offers if it retires it). Free, no credit card: sign in at console.groq.com/keys, create a key and paste it here. The free plan allows about 1,000 requests a day and 30 a minute; what's left today shows above after you polish. Your key is stored only in this browser.

Right-click menu

The same as the switch in the side panel (tab 2).

How it works

Select text, or right-click in a text field (its whole text is used when nothing is selected), and pick Polish text. A card opens at the bottom-right. Rephrase (the default) rewrites it to read better, in the tone you pick: clearer, shorter, friendly, formal or casual. Fix corrects spelling, grammar and punctuation and changes as little as possible. The card remembers your last choice. You can edit the result, then replace the text in the field with it, or copy it. Only the text you rewrite is sent to Groq, and nothing else from the page. It answers in the language the text is written in.

enable copy & right-click

For sites that stop you selecting, copying or right-clicking. It's never on everywhere: switch it on for the site you're on with enable copy & right-click in the tools. Remember this site (ticked when you switch it on) keeps it unlocked on every visit; untick it to unlock only until Chrome closes. Switching it off forgets the site. A site covers its subdomains.

Remembered sites unlocked on every visit

Until Chrome closes unlocked without "remember"

How it works

The page's own code isn't switched off (that would break menus, editors and drag & drop): it keeps running but can't cancel a copy, a right-click or selecting text: the site's own right-click menu still opens, and Chrome's opens too. Text fields and editors are left alone, since web apps handle copy and right-click there themselves, and so are buttons, links and other controls. Text that can't be selected is made selectable, and a selection hidden with an invisible color is shown again. It's in place before the page's own scripts run, and switching it off takes effect without a reload.

      remove elements

      Sites click a name to turn it off or on · × deletes it · hover for its address · removals apply to the whole site and its subdomains

      How it works

      In the tools, page tab → remove elements → pick, then click everything you want gone (↑ selects the parent, Ctrl/⌘+Z puts the last one back, Esc or Enter when done). While picking, a panel in the corner lists what's removed on the site: point at an entry to see that element, the eye shows it again (or hides it again), × deletes it, and discard all puts back everything picked in that session without saving it. Removed elements stay hidden on every later visit — the page is held back until they're hidden, so they never flash, even on slow loads. Show removed on this site brings them back with a red dashed outline until you switch it off or restart Chrome.

      highlight words

      Look how marks are drawn on pages · examples use the global list's color

      Lists the global list marks every site; a site's own list marks only that site (and its subdomains), drawn over the global one

      How it works

      Pick a list on the left to edit it on the right; the switch beside each list turns it off without deleting it. Words and phrases are matched as whole words (or anywhere inside words, with Match → inside words too for that list), any case, and marked as pages load and change (infinite scroll, in-app navigation, live updates) without touching the page itself. A site's own list is drawn over the global one where both match. Limits: 1,000 global words, 300 per site, 200 sites, 100 characters each; at most 5,000 marks per page. CSV (in a list's ⋯ menu): one word or phrase per row (first column; a "word" header is fine). Import adds to the list and skips duplicates. In the tools: the main switch, exclude <site> from global, and <site> list to switch a site's list off without deleting it.

      Auto-sync

      A snapshot is saved only when something changed: your bookmarks, and Extra Guac's settings and data (API keys included, blur rules, removed elements, histories). Older ones thin out like a time machine — the 3 latest, about 1 week, 2 weeks, 1 month, 2 months, 6 months and 1 year old, and the oldest one forever. Each browser's latest is always kept, and so is the copy taken before every restore or import (for 30 days).

      Snapshots

      Connect Google Drive or Dropbox to see your snapshots.

      restore settings replaces Extra Guac's settings and data with the snapshot's. restore bookmarks adds the snapshot's bookmarks in a new folder under Other bookmarks, next to the ones you have now. .html saves them as a bookmarks file any browser can import. Before every restore or import, the current settings are saved first — undo last restore below puts them back.

      Settings file

      Extra Guac's settings and data as a .json file, API keys included (not the Google or Dropbox sign-in) — keep it somewhere private. Import takes such a file or a Drive or Dropbox snapshot (.json.gz) and replaces the current settings and data. Session switch profiles (saved logins) are only in the file when you tick the box above: they're encrypted with your passphrase (PBKDF2 and AES-GCM), which isn't stored anywhere. Importing such a file asks whether to bring them back too; they're added next to the profiles already here.

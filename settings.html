      How it works

      Turn it on per tab in the popup: a fixed interval, or a random one between two values (seconds). The keyword is matched against the page's visible text, ignoring case. The toolbar badge counts down on that tab.

      url shortener

      Keys are stored only in this browser. Links are counted per calendar month on this device; the free-plan limits shown are cutt.ly 30, TinyURL 30 and dub.co 25 links a month.

      ondomainfindreplace withauto

      Try a URL

      How rules work

      docs.google.comdomain: that site and its subdomains. Empty = every site. A path (docs.google.com/spreadsheets) means "URL contains"; anything with \ ( * | is a regex.
      SY500 → SY1600find plain text: replaced as is (first match).
      /edit{line} → /copy{line} = rest of the URL, {word} = one path part, {number} = digits, {[a-z-]} = your own characters. Insert them in the target with {1}, {2}…
      /www(\.)/ → old$1regex in slashes, with flags after (/…/gi); use $1 or $<name>.
      auto ✓ / ✗Auto rules redirect as the page starts loading. The others run from the page's right-click menu, Redirect with rules.
      loopsA tab is never redirected again from a URL a rule just sent it to, and more than 4 redirects in 10 s pauses redirecting that tab for a minute.

      image upload

      Catbox

      Without a userhash uploads are anonymous. With it they're saved to your account (find it at catbox.moe → Manage account).

      x02

      x02 has no anonymous uploads, so it's only available once your key checks out. Get a key at x02.me.

      How it works

      Right-click any image → Upload image to … (with both hosts on, the item branches into the two). The link is copied, a notification confirms it, and it's listed in the popup's upload history. The host fetches the image itself; if it can't (private or embedded images), Tab Toolkit downloads it and uploads the file.

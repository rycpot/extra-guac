Allow Extra Guac to run userscripts

Userscripts are small programs you add yourself that change how sites look or work. Chrome asks you once before Extra Guac can run them.

Chrome needs one more switch

Chrome only lets an extension run scripts you add when you allow it on the extension's own page.

  1. Click open extension details below.
  2. Turn on Allow User Scripts (in older Chrome versions: Developer mode, at the top right of the extensions page).
  3. Come back here. This message goes away by itself.

Chrome 131 or later is needed

Update Chrome (menu → Help → About Google Chrome), then come back here.

Backup

Import takes a .zip export, a userscript backup text file (.txt or .json) or .user.js files, with what the scripts saved when the file has it. A script with the same name and namespace as one here takes its place; anything else is added.

Only the scripts and what they saved change; every other setting stays as it is. Scripts are also part of every Drive backup and full restore, and undo last restore (in settings → backup) puts back what was here before.
